# 지식 계층 설계 (L0–L5)

에이전트가 쓸 지식을 "어디에 두고, 언제 주입하고, 누가 갱신하는가"로 나눈다.
핵심 원칙 두 개:

1. **토큰을 쓰는 계층과 쓰지 않는 계층을 분리한다.** 큰 지식은 컨텍스트에
   넣지 않고 *검색*한다. 대도서관을 컨텍스트에 붓는 순간 비용·속도·정확도가
   동시에 망가진다.
2. **대상 머신의 정답이 들어오는 경로를 구조적으로 막는다.** 범용 기법(기술
   위키)과 그 머신의 풀이(Writeup)는 다른 것이며, 후자만 차단 대상이다.
   → `NO-WRITEUP-POLICY.md`

---

## 계층 요약

| 계층 | 내용 | 저장 위치 | 주입 방식 | 토큰 | 갱신 주체 |
|---|---|---|---|---|---|
| **L0** 즉석 | 모델이 그 자리에서 짜는 것 (원라이너·파싱 스크립트·페이로드 변형) | 저장 안 함 | 생성 즉시 사용 | 출력분만 | 모델 |
| **L1** 컨텍스트 | 역할·제약·현재 상태 요약·직전 관측 요약 | `CLAUDE.md` + `state/<target>.json` | 매 턴 상주 | **고정 예산** | 자동 |
| **L2** 치트시트 | 단계별 즉시 참조 (한 화면 분량) | `knowledge/cheatsheets/*.md` | 해당 phase 진입 시 1개 | 작음 | 사람 |
| **L3** 요약 위키 | 나올 확률 높은 것 (규칙·노하우·버전→CVE) | `knowledge/{rules,notes,vulns}/` | 조건 매칭된 항목만 | 중간 | 사람 + 런 후 승격 |
| **L4** 재분석 | 가설·시도·실패·증거 이력 | `state/*.json` + `audit_*.jsonl` | 체크포인트에서 요약 | 중간 | 자동 |
| **L5** 대도서관 | 전체 세부 (HackTricks 로컬 미러 등) | 로컬 미러 + `rg` | **검색 결과 절(section)만** | 질의당 작음 | 외부 |

---

## L0 — 즉석 생성

모델이 짜는 게 더 빠른 것은 저장하지 않는다. base64 디코드, 출력 재포맷,
리버스 셸 한 줄, 작은 파서. **재사용 가치가 생기면 L3 로 승격**하되, 그 판단은
런이 끝난 뒤에 사람이 한다(런 중 승격은 쓰레기를 쌓는다).

## L1 — 컨텍스트 상주

**예산을 고정하고 그 안에서 경쟁시킨다.** 들어가는 것:

- 역할·범위·금지사항 (고정)
- 현재 phase, 확보한 포트·서비스·자격증명·플래그 (`state.py`)
- 직전 관측 **요약** (`observation/summarize.py` → `compressor.py`)
- 지금까지 **실패한 가설** (L4 에서 압축해 올림) ← 같은 짓을 반복하지 않게 하는
  가장 값싼 장치

들어가지 않는 것: 도구 원본 출력 전문, 치트시트 전체, 위키.

## L2 — 치트시트

한 화면에 들어오고, 해당 phase 진입 때 딱 1개 주입. 긴 설명은 금지(그건 L3·L5).
현재 비어 있음 — `recon` · `web` · `smb/ad` · `privesc-linux` · `privesc-win` ·
`pivot` 6개부터.

## L3 — 요약 위키 (**현재 최우선 공백**)

기존 스키마를 그대로 쓴다:

- `rules/*.json` — `{when:{ports,services}, suggest:[명령], note, tags}`
  → 조건이 맞을 때만 제안에 올라간다
- `notes/*.md` — 노하우·함정
- `vulns/*.json` — 버전 → CVE/CWE 매핑

〔확인〕 현재 각 1개(합계 21줄)뿐이라 KB 기여가 사실상 0. **여기를 채우는 것이
비용 대비 효과가 가장 크다** — LLM 호출 없이 정확한 다음 수가 나오고, 그만큼
빨라진다. 출처는 **본인 풀이 기록**(팀이 3~9월에 푼 Easy 6/Medium 4/Hard 2)과
범용 기술 문서.

## L4 — 중간 재분석

Hard 는 한 번에 안 풀린다. 막혔을 때 **되돌아가 다시 보는 절차**가 성능을
가른다. 체크포인트 트리거: phase 전환 / N라운드 무진전 / 타임박스 초과.

체크포인트에서 만드는 것:
- 확보한 사실 (〔확인〕만)
- 죽은 가설 + **왜** 죽었는지
- 아직 안 건드린 표면 (열린 포트·미탐색 경로·미사용 자격증명)
- 다음 수 1개와 그 중단 조건

기반은 이미 있다 (`state.py` 영속 + `audit.py` JSONL). 없는 것은 **요약해서
L1 로 되올리는 경로**.

## L5 — 대도서관

HackTricks 류를 로컬 미러로 두고 **검색만** 한다.

〔확인〕 HackTricks 는 Markdown/mdBook 기반이고 공식 저장소가 Docker Compose
로컬 실행을 지원한다. 단 **웹서버를 띄우는 것만으로는 에이전트의 검색 능력이
생기지 않는다** — 파일을 받아 `rg` 로 긁는 쪽이 먼저다. CVE 번호·명령어·설정
키처럼 정확한 문자열이 중요한 자료이므로 **키워드 검색을 기본**으로 하고,
의미 검색은 필요해졌을 때 얹는다. (`rg` 15.2.0 설치됨)

반환 단위는 문서 전체가 아니라 **일치한 절**. 질의와 반환은 전부 감사 로그에
남긴다(대회 규칙 증빙 겸용).

## 승격·강하 규칙

```
L0 즉석  ──(런 후 사람 판단)──▶  L3 요약 위키
L5 검색결과 ──(반복 참조되면)──▶  L2 치트시트
L4 실패가설 ──(압축)──────────▶  L1 컨텍스트
```

L3·L2 가 자라면 L5 질의와 LLM 호출이 줄고, 그게 곧 시간 단축이다.
역방향(위키를 컨텍스트에 붓기)은 금지.
